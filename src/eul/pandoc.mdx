## About Pandoc

[Pandoc](http://pandoc.org/), created by
[John MacFarlane](http://johnmacfarlane.net/), is the document swiss army
knife. It is at once a command-line tool for converting between document
formats, a [Haskell](https://www.haskell.org/) library for reading,
transforming and writing structured documents, and a formal document
meta-model specification. While appreciating Haskell, this Python library
was created — as a Haskell beginner — to broaden accessibility to pandoc's
capabilities.
